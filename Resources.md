# DSA Learning Resources

A curated list of high-quality resources for learning Data Structures and Algorithms in Java.

---

## 📚 Books

### Essential
1. **Introduction to Algorithms (CLRS)** by Cormen, Leiserson, Rivest, and Stein
   - Comprehensive theoretical foundation
   - Mathematical approach to algorithms
   - Industry standard reference

2. **Cracking the Coding Interview** by Gayle Laakmann McDowell
   - Interview-focused problem solving
   - 189 programming questions with solutions
   - Tips for technical interviews

3. **Effective Java** by Joshua Bloch
   - Java best practices
   - How to write better Java code
   - Essential for Java developers

4. **Data Structures and Algorithms in Java** by Robert Lafore
   - Java-specific implementation
   - Visual approach with diagrams
   - Beginner-friendly

### Supplementary
5. **Algorithms** by Robert Sedgewick and Kevin Wayne
6. **The Algorithm Design Manual** by Steven Skiena
7. **Elements of Programming Interviews in Java** by Adnan Aziz

## 📝 Additional Tips

### How to Use These Resources
1. **Start with fundamentals** - Don't jump to advanced topics
2. **Be consistent** - 2-3 hours daily is better than 10 hours once a week
3. **Mix theory and practice** - Read concepts, then solve problems
4. **Join communities** - Learn from others, ask questions
5. **Track progress** - Use the Progress Tracker in this repo
6. **Review regularly** - Revisit solved problems

### Recommended Learning Path
1. Start with HackerRank Java track (1-2 weeks)
2. Read CTCI while solving easy LeetCode problems (1 month)
3. Follow the structured plan in this repository
4. Join weekly LeetCode contests
5. Focus on companies you're targeting

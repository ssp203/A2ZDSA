# Data Structures

This directory contains implementations of fundamental data structures from scratch.

## Subdirectories
- `arrays/` - Array-based implementations
- `linkedlist/` - Singly, doubly, and circular linked lists
- `stack/` - Stack implementations
- `queue/` - Queue, Deque, Priority Queue
- `tree/` - Binary trees, BST, AVL, etc.
- `graph/` - Graph representations and implementations
- `heap/` - Min heap and max heap
- `hashtable/` - Custom hash table implementation

## Learning Approach
1. Understand the data structure conceptually
2. Implement from scratch without using library classes
3. Analyze time and space complexity
4. Compare with Java Collections Framework implementations

# Algorithms

This directory contains implementations of fundamental algorithms.

## Categories
- `sorting/` - Bubble, Selection, Insertion, Merge, Quick, Heap sort
- `searching/` - Linear, Binary, Ternary search
- `recursion/` - Recursive problem solutions
- `backtracking/` - Backtracking algorithms
- `dp/` - Dynamic programming solutions
- `greedy/` - Greedy algorithm implementations
- `graph/` - Graph algorithms (BFS, DFS, Dijkstra, etc.)

## Learning Tips
- Understand the algorithm's logic before coding
- Trace through examples manually
- Analyze time and space complexity
- Compare different algorithms for the same problem

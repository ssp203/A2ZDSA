# Medium Difficulty Problems

This directory contains solutions to medium difficulty DSA problems.

## Problem Selection Criteria

Medium problems typically involve:
- Multiple data structures or algorithms combined
- Optimization of brute force solutions
- Moderate complexity patterns (two pointers, sliding window, BFS/DFS)
- Some algorithmic thinking required
- Time/space complexity optimization

## Learning Path

### Phase 1: Master Patterns
1. Two pointers and sliding window
2. Fast & slow pointers (linked list)
3. BFS and DFS traversals
4. Basic dynamic programming

### Phase 2: Intermediate Techniques
1. Backtracking problems
2. Binary search variations
3. Heap-based problems
4. Graph algorithms (topological sort, cycle detection)

### Phase 3: Advanced Patterns
1. Advanced DP (2D, state machines)
2. Monotonic stack/queue
3. Union-Find
4. Trie-based problems

## Study Tips

1. **Understand the pattern**: Recognize problem types
2. **Start with brute force**: Get a working solution first
3. **Optimize gradually**: Improve time/space complexity step by step
4. **Multiple approaches**: Try to solve in 2-3 different ways
5. **Test edge cases**: Empty input, single element, large input
6. **Time yourself**: Aim for 30-45 minutes per problem
7. **Review solutions**: Learn from optimal approaches

## Common Medium Problem Patterns

### Pattern Recognition

- **"Find all"**: Often backtracking or DFS
- **"Maximum/Minimum subarray"**: DP or sliding window
- **"K closest/largest/smallest"**: Heap
- **"Level order"**: BFS with queue
- **"Path in tree/graph"**: DFS or BFS
- **"Sorted array"**: Binary search or two pointers
- **"Unique combinations"**: Backtracking
- **"Consecutive elements"**: Sliding window or hash map

## Complexity Goals

For medium problems:
- **Time**: Usually O(n), O(n log n), or O(n²)
- **Space**: Usually O(n) or O(log n)
- Avoid O(n³) or exponential unless specifically needed

## Interview Preparation

### Before the Interview
- Practice 50-100 medium problems
- Master 10-15 common patterns
- Can solve most in 30-40 minutes
- Comfortable explaining approach

### During the Interview
1. Clarify problem and constraints
2. Discuss approach before coding
3. Start with brute force if needed
4. Optimize step by step
5. Test with examples
6. Analyze complexity

## Tips for Success

1. **Consistency**: Solve 1-2 problems daily
2. **Active recall**: Revisit problems after 1 week, 1 month
3. **Understand, don't memorize**: Focus on patterns
4. **Time management**: Don't spend more than 45 minutes initially
5. **Learn from solutions**: Study optimal approaches
6. **Discuss with peers**: Explain your solutions
7. **Track weak areas**: Focus on problem types you struggle with

# Problems

This directory contains solutions to practice problems from various platforms.

## Organization
- `easy/` - Easy difficulty problems
- `medium/` - Medium difficulty problems
- `hard/` - Hard difficulty problems

## Problem Template
Each problem solution should include:
1. Problem statement (as comment)
2. Approach explanation
3. Time and space complexity
4. Multiple test cases
5. Clean, well-commented code

## Sources
- LeetCode
- HackerRank
- GeeksforGeeks
- Codeforces
- InterviewBit

## Tracking Progress
Keep a log of problems solved with:
- Problem name
- Platform
- Difficulty
- Date solved
- Topics/patterns used
